# Miniature Creator V1

Mobilfreundliche React/Vite-Weboberfläche mit Texteingabe, Größenauswahl (32/75/200 mm) und interaktivem 3D-Demomodell. **Keine echte KI-Generierung und kein STL-Export in dieser Version.**

## Lokal starten
`npm install` und `npm run dev`

## Netlify
GitHub-Repository verbinden. Build command: `npm run build`; Publish directory: `dist`. `netlify.toml` enthält diese Einstellungen bereits.

## Nächste Schritte
Serverseitige KI-API (Schlüssel niemals im Frontend), Jobstatus, Download und Mesh-Prüfung, GLB-Vorschau, STL-Export.
